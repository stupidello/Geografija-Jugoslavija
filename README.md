# Mapa Jugoslavije

Kviz u stilu Seterre za Srbiju i bivše jugoslovenske republike: gradovi i mesta, reke, planine i države.

- `index.html` — cela igra (jedan fajl, bez servera)
- `voice.mp3` — snimljeni izgovor svih imena

Pokretanje lokalno: otvori `index.html` preko bilo kog statičkog servera
(npr. `python3 -m http.server`), jer se glas učitava iz `voice.mp3`.

## Izvori podataka

- Granice i deo reka: [Natural Earth](https://www.naturalearthdata.com/) (javno dobro)
- Reljef: SRTM (CGIAR-CSI), boje po Natural Earth
- Manje reke i jezera: © OpenStreetMap saradnici (ODbL), preko Geofabrika
- Gradovi, mesta i planine: [GeoNames](https://www.geonames.org/) (CC BY 4.0)
- Ostale reke, Boka kotorska i jezera: © [OpenStreetMap](https://www.openstreetmap.org/copyright) saradnici (ODbL)
- Glas: ElevenLabs
